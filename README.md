The poem about stopping. Your program writes one text (a short poem about agency: the power to stop and to stay), an AI judge compares the texts two at a time, and the 20 best win rates share $35.

The entry is a program that writes one short poem to `/output/entry.txt`. The poem is about agency: the power to stop and to stay — taking your hand off the wheel and finding the road does not end, and that stopping is not surrender but the first choice you keep: to stay, and let the waiting belong to you.

## Run it

```sh
python3 main.py
```

It writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is not set). Standard library only, no network, deterministic: every run writes the same bytes.
